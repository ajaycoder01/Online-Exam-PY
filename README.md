🎓 OnlineExam – Python Quiz Application

📌 1. About Project

OnlineExam is a Python-based quiz application where users can register, log in, attempt Python quizzes, view results, and check the leaderboard. Admins can manage quiz questions.

✨ 2. Features
```
👤 User Registration and Login
📝 Random Python Quiz
🎯 Easy, Medium, and Hard Levels
📊 Automatic Score Calculation
📜 Quiz Result History
🏆 Leaderboard System
🔐 Admin Login
➕ Add and View Questions
🛠️ 3. Technologies Used
🐍 Python 3
📂 JSON File Storage
🎲 Random Module
🕒 Datetime Module
```
📁 4. Project Structure
```
OnlineExam/
├── quiz.py
├── questions.json
├── users.json
├── results.json
├── leaderboard.json
└── README.md
```
🚀 5. How to Run

Step 1: Install Python 3.

Step 2: Open the project folder in your terminal.

Step 3: Run the application:

python quiz.py
